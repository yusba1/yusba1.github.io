# Mingqiao Zhang · 张茗侨

Personal homepage featuring selected research and projects.

The desktop layout pairs a persistent personal profile with one continuous
reading column. On smaller screens, the profile and content form a single column.
Each paper and project appears once.

**Website: https://yusba1.github.io/**

## Contents

- Three selected papers: one IJCAI-ECAI 2026 paper and two arXiv preprints
- George Interview: product demonstration and competition recognition
- Education, honors, and contact information

## Local preview

Open `index.html` directly, or run:

```sh
python -m http.server 8765
```

Then visit `http://localhost:8765`.

## Editing

The site uses plain HTML, CSS, and JavaScript without a build step.

- `index.html` — page content
- `styles.css` — responsive layout and visual styles
- `script.js` — navigation, image viewer, and citations
- `assets/` — research figures, project images, and demo video

GitHub Pages can publish directly from the `main` branch, `/ (root)` folder. `.nojekyll` disables Jekyll processing.
